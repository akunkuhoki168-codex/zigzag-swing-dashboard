# ADX Swing dashboard

Public live view of the **ADX Swing** alert-only bot (Binance USD-M Futures ATR zigzag BUY/SELL, plus a 1-minute ADX scanner).

Live page: https://dedkovic441-hub.github.io/adx-swing-dashboard/

`data.json` is regenerated and pushed about every 2 minutes when anything material has changed. The page also refreshes prices directly from Binance and reloads this file every 30 seconds.

All times on the page are in WIB (Asia/Jakarta, UTC+7).

This is an alert dashboard only. No orders are placed. Not financial advice.

The live chart is at https://dedkovic441-hub.github.io/adx-swing/.
